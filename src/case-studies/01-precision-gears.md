## The brief

A compact gear set intended for **fit and motion testing**. The main goal is not cosmetic perfection — it’s a predictable mesh and a consistent result from one print to the next.

## What mattered

- **Tooth definition** (sharpness and consistency across the gear)
- **Repeatable fit** on shafts and mating parts
- Strength and layer adhesion suitable for handling and testing

## How we approached it

For gears, orientation and settings matter because small changes can show up as noise in the mesh. PETG is a strong all‑round choice for functional prototypes: it prints cleanly, handles everyday loads well, and typically provides better durability than PLA for moving interfaces.

Before printing, we check the model for common issues: under-supported teeth, too-thin features, and tight clearances on shafts/bores. If fit is critical, we can validate with a quick test piece (or an initial print) and adjust clearances based on measurements.

## Outcome

A functional printed gear set suitable for motion testing and iteration. If the next step is a repeat order or a small batch, we can keep a confirmed spec (material, settings, and any critical dimensions) so reorders behave predictably.

## Options

- Need a tougher feel or more temperature resistance? Consider **ABS/ASA** depending on the environment.
- If you need a tighter fit, we can run a measurement-led iteration (test print → measure → adjust → reprint).
