## The brief

An accessory mount intended to fit an existing device. The goal is a quick prototype that’s rigid, accurate enough to assemble, and easy to iterate.

## What mattered

- Rigid geometry for stable mounting
- Clean mating faces and practical tolerances
- Fast turnaround to support iteration

## How we approached it

PLA is often the most efficient way to iterate on functional geometry: it prints cleanly, holds crisp detail, and is cost-effective for prototypes and accessories that won’t see high heat.

We review the key interfaces (mating surfaces, holes, and alignment features) and print with a setup that balances speed and consistency. If a tight interface is required, we can validate with a small test piece first.

## Outcome

A functional accessory mount suitable for assembly and evaluation, ready for the next iteration if needed.

## Options

- If the part will see more mechanical stress or mild heat, **PETG** is often a better choice.
- For tighter requirements, we can run an iteration loop (test print → measure → adjust).
